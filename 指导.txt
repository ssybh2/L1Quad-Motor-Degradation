PX4 v1.17.0 L1Quad 操作指导

本项目是研究用飞控代码。刷写、HITL 和真机拆桨测试时必须拆除所有螺旋桨。

==================== 第一部分：操作步骤 ====================


一、目录约定

以下命令均假设当前终端位于工作区根目录，目录结构为：

./
├── Ardupoilt-to-PX4/
├── PX4-Autopilot-v1.17.0/
├── PX4-Autopilot-v1.17.0-HITL/
├── PX4-Autopilot-v1.17.0-MAIN/
└── L1Quad-firmware/

工作区可以放在任意位置。后续命令全部使用相对路径。

分支用途：

main  真机固件基线和两个 L1 失效飞行模式
hitl  Pixhawk 6C Mini + SIH/jMAVSim 硬件在环
sitl  Gazebo Harmonic、键盘、QGC Joystick 和仿真电机失效

查看分支：

git -C ./Ardupoilt-to-PX4 branch --show-current

切换分支：

git -C ./Ardupoilt-to-PX4 switch main
git -C ./Ardupoilt-to-PX4 switch hitl
git -C ./Ardupoilt-to-PX4 switch sitl


二、预编译固件

仓库内可直接刷写的 Pixhawk 6C Mini 固件：

./Ardupoilt-to-PX4/firmware/pixhawk6cmini/L1Quad-main-pixhawk6cmini.px4
./Ardupoilt-to-PX4/firmware/pixhawk6cmini/L1Quad-hitl-pixhawk6cmini.px4
./Ardupoilt-to-PX4/firmware/pixhawk6cmini/L1Quad-sitl-pixhawk6cmini.px4

工作区集中保存的副本：

./L1Quad-firmware/

用途：

main  真机准备和拆桨验证
hitl  SIH/jMAVSim 硬件在环
sitl  sitl 分支的硬件目标快照；Gazebo SITL 不需要刷写飞控

QGC 手动切换固件：

1. 拆除螺旋桨，关闭 jMAVSim。
2. USB 连接飞控并打开 QGC。
3. 进入 Vehicle Setup -> Firmware。
4. 选择 Advanced settings -> Custom firmware file。
5. 选择需要的 .px4 文件。
6. 等待 Erase、Program、Verify 完成并自动重启。
7. 重连 QGC，检查机型、遥控器、飞行模式和参数。


三、Gazebo Harmonic SITL

启动：

make -C ./PX4-Autopilot-v1.17.0 px4_sitl gz_x500

出现 pxh> 后输入：

param set CA_FAILURE_MODE 1
mc_rate_control stop
l1_adaptive_control start
l1_adaptive_control rc_control enable
commander arm -f

飞机会自动起飞到约 1 m 并悬停。

检查：

l1_adaptive_control status
listener vehicle_local_position 1
listener failure_detector_status 1


四、SITL 键盘控制

飞机稳定悬停后输入：

l1_keyboard_throttle start

按键不需要回车：

w          上升
s          下降
x 或空格   保持当前目标高度
0          Motor 1 失效
r          Motor 1 恢复
q          退出键盘工具并返回 pxh>

结束仿真：

shutdown


五、QGC Joystick

QGC 中完成 Joystick 校准，并将一个两段拨杆映射到 AUX1。

在 pxh> 输入：

param set COM_RC_IN_MODE 2
param set CA_FAILURE_MODE 1
mc_rate_control stop
l1_adaptive_control start
l1_adaptive_control rc_control enable
commander arm -f

使用 Joystick 时不要启动 l1_keyboard_throttle。

AUX1 低位为 Motor 1 正常，高位为 Motor 1 失效。起飞前必须保持低位。

检查拨杆：

listener manual_control_setpoint 5

L1 优先使用有效 input_rc；RC 无效时回退到 QGC Joystick 的
manual_control_setpoint。


六、HITL：Pixhawk 6C Mini + SIH + jMAVSim

HITL 测试必须拆除螺旋桨。先关闭 QGC，避免它抢占飞控 USB。

先启动 jMAVSim：

./PX4-Autopilot-v1.17.0-HITL/Tools/simulation/jmavsim/jmavsim_run.sh \
  -q -s \
  -d /dev/serial/by-id/usb-Auterion_PX4_FMU_v6C.x_0-if00 \
  -b 2000000 -o

保持 jMAVSim 终端运行，再打开 QGC。QGC 通过 UDP 桥接连接飞控。

如果 USB 设备名不同，先查看：

ls -l /dev/serial/by-id/

当前已验证的主要 SIH 参数：

SYS_AUTOSTART = 1100
SYS_HITL = 2
SIH_MASS = 0.62
SIH_IXX = 0.002016
SIH_IYY = 0.001827
SIH_IZZ = 0.00322
SIH_T_MAX = 11.3655
SIH_T_TAU = 0.02
SIH_L_ROLL = 0.175
SIH_L_PITCH = 0.131
THR_MDL_FAC = 0
L1_MOT1_SCALE = 0.8

飞控重启后，如果 jMAVSim 不再更新，关闭 jMAVSim 并按上述命令重新启动。


七、L1 失效飞行模式

QGC Flight Modes 中可以配置：

L1 Failure
  基于 Position；Motor 1 按参数降低输出，保持位置、高度和偏航。

L1 Altitude Failure
  基于 Altitude；Motor 1 按参数降低输出，横滚/俯仰摇杆控制倾角，
  油门控制升降，不保持水平位置，并保持偏航。

测试顺序：

1. 安全位置设置为 Position。
2. 正常解锁、起飞并稳定悬停。
3. 油门保持中位，横滚和俯仰保持中位。
4. 切入一个 L1 失效模式。
5. 确认 Motor 1 保留 L1_MOT1_SCALE 指定的输出且飞机未快速翻落。
6. 拨回 Position，确认 Motor 1 恢复100%输出。
7. 降落并锁定。

两个 L1 失效模式都禁止用于解锁，只能在正常起飞后切入。
控制器在失效模式继续保持 yaw，不应持续绕 yaw 旋转。

检查状态：

l1_adaptive_control status
listener vehicle_status 1
param show L1_MOT1_SCALE
control_allocator status

L1 Failure 的 nav_state 为 16。
L1 Altitude Failure 的 nav_state 为 7。

修改质量或惯量时必须同时修改上述两个 .cpp 文件。JINV_XX、JINV_YY、
JINV_ZZ 分别等于三个惯量的倒数，不能作为独立参数随意调整。

起飞、圆轨迹和手动高度参数：

./Ardupoilt-to-PX4/l1_adaptive_control/TrajectoryGenerator.hpp:113-120

TAKEOFF_HEIGHT_M、TAKEOFF_DURATION_S
CIRCLE_RADIUS_M、CIRCLE_SPEED_M_S
MANUAL_HEIGHT_DEADZONE、MANUAL_MAX_CLIMB_RATE_M_S
MANUAL_MIN_HEIGHT_M、MANUAL_MAX_HEIGHT_M

自动启动开关：

./Ardupoilt-to-PX4/l1_adaptive_control/l1_adaptive_control_params.c:10

L1_FAIL_EN = 1
L1_MOT1_SCALE = 0.8

上述 constexpr 参数修改后必须重新编译并刷写固件。L1_FAIL_EN 和
L1_MOT1_SCALE 是 PX4 运行时参数，可以通过 QGC 或 param set 修改，
不需要重新编译。L1_MOT1_SCALE 表示 Motor 1 剩余输出指令比例；
真机实际推力比例受 ESC、电机和螺旋桨曲线影响，带桨前必须标定。


==================== 第二部分：排错与安全说明 ====================


十、常见问题

QGC 识别不到 Joystick：

确认发射机选择 USB Joystick/HID 模式，并在 QGC 的
Vehicle Setup -> Joystick 中重新校准。

RC 摇杆正常但拨杆没有 AUX1：

确认发射机输出对应通道，并在 QGC Joystick 或 RC 通道映射中将该通道
分配给 AUX1。使用 listener manual_control_setpoint 5 或
listener input_rc 5 检查。

切换失效模式没有反应：

检查 L1 是否运行、nav_state 是否为 16 或 7，并检查
L1_MOT1_SCALE 和 control_allocator status。

jMAVSim Port busy：

关闭 QGC 和旧 jMAVSim，再严格按“先 jMAVSim、后 QGC”的顺序启动。

Gazebo 出现 gz_frame_id、LED 或无 GCS 警告：

SITL 传感器、EKF 和起飞功能正常时，这些通常是仿真环境提示。

切换后飞机持续旋转：

当前版本在电机降级时继续保持 yaw。持续旋转不是预期现象，应立即切回
Position 并检查电机编号、方向、输出比例和 yaw 控制输出。


十一、安全边界

- SITL 中可以使用 commander arm -f；真机禁止强制解锁。
- SITL 专用故障保护设置不得直接复制到真机。
- 真机首次验证必须拆桨，并检查电机编号、方向和拨杆安全位置。
- 真机飞行前需要重新确认质量、惯量、机臂、电机和螺旋桨参数。
