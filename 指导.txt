PX4 v1.17.0 L1Quad 操作指导

本项目是研究用飞控代码。刷写、HITL 和真机拆桨测试时必须拆除所有螺旋桨。

==================== 第一部分：操作步骤 ====================


一、目录约定

以下命令均假设当前终端位于工作区根目录，目录结构为：

./
├── Ardupoilt-to-PX4/
├── PX4-Autopilot-v1.17.0/
├── PX4-Autopilot-v1.17.0-HITL/
├── PX4-Autopilot-v1.17.0-MAIN/
└── L1Quad-firmware/

工作区可以放在任意位置。后续命令全部使用相对路径。

分支用途：

main  真机固件基线和两个 L1 失效飞行模式
hitl  Pixhawk 6C Mini + SIH/jMAVSim 硬件在环
sitl  Gazebo Harmonic、键盘、QGC Joystick 和仿真电机失效

查看分支：

git -C ./Ardupoilt-to-PX4 branch --show-current

切换分支：

git -C ./Ardupoilt-to-PX4 switch main
git -C ./Ardupoilt-to-PX4 switch hitl
git -C ./Ardupoilt-to-PX4 switch sitl


二、预编译固件

仓库内可直接刷写的 Pixhawk 6C Mini 固件：

./Ardupoilt-to-PX4/firmware/pixhawk6cmini/L1Quad-main-pixhawk6cmini.px4
./Ardupoilt-to-PX4/firmware/pixhawk6cmini/L1Quad-hitl-pixhawk6cmini.px4
./Ardupoilt-to-PX4/firmware/pixhawk6cmini/L1Quad-sitl-pixhawk6cmini.px4

工作区集中保存的副本：

./L1Quad-firmware/

用途：

main  真机准备和拆桨验证
hitl  SIH/jMAVSim 硬件在环
sitl  sitl 分支的硬件目标快照；Gazebo SITL 不需要刷写飞控

QGC 手动切换固件：

1. 拆除螺旋桨，关闭 jMAVSim。
2. USB 连接飞控并打开 QGC。
3. 进入 Vehicle Setup -> Firmware。
4. 选择 Advanced settings -> Custom firmware file。
5. 选择需要的 .px4 文件。
6. 等待 Erase、Program、Verify 完成并自动重启。
7. 重连 QGC，检查机型、遥控器、飞行模式和参数。


三、Gazebo Harmonic SITL

启动：

make -C ./PX4-Autopilot-v1.17.0 px4_sitl gz_x500

出现 pxh> 后输入：

param set CA_FAILURE_MODE 1
mc_rate_control stop
l1_adaptive_control start
l1_adaptive_control rc_control enable
commander arm -f

飞机会自动起飞到约 1 m 并悬停。

检查：

l1_adaptive_control status
listener vehicle_local_position 1
listener failure_detector_status 1


四、SITL 键盘控制

飞机稳定悬停后输入：

l1_keyboard_throttle start

按键不需要回车：

w          上升
s          下降
x 或空格   保持当前目标高度
0          Motor 1 失效
r          Motor 1 恢复
q          退出键盘工具并返回 pxh>

结束仿真：

shutdown


五、QGC Joystick

QGC 中完成 Joystick 校准，并将一个两段拨杆映射到 AUX1。

在 pxh> 输入：

param set COM_RC_IN_MODE 2
param set CA_FAILURE_MODE 1
mc_rate_control stop
l1_adaptive_control start
l1_adaptive_control rc_control enable
commander arm -f

使用 Joystick 时不要启动 l1_keyboard_throttle。

AUX1 低位为 Motor 1 正常，高位为 Motor 1 失效。起飞前必须保持低位。

检查拨杆：

listener manual_control_setpoint 5

L1 优先使用有效 input_rc；RC 无效时回退到 QGC Joystick 的
manual_control_setpoint。


六、HITL：Pixhawk 6C Mini + SIH + jMAVSim

HITL 测试必须拆除螺旋桨。不能让 jMAVSim 直接独占飞控 USB，否则
QGC 虽然能收到飞行数据，但 MAVLink Console 中的 NSH 可能没有回显。

先关闭 QGC 和旧 jMAVSim。终端 1 启动串口透明桥：

python3 ./Ardupoilt-to-PX4/scripts/mavlink_serial_udp_bridge.py \
  --device /dev/serial/by-id/usb-Auterion_PX4_FMU_v6C.x_0-if00 \
  --baud 2000000 \
  --bind-port 14570 \
  --endpoint 127.0.0.1:14550 \
  --endpoint 127.0.0.1:14560 \
  --endpoint 127.0.0.1:14540

保持终端 1 运行。终端 2 通过 UDP 启动 jMAVSim：

./PX4-Autopilot-v1.17.0-MAIN/Tools/simulation/jmavsim/jmavsim_run.sh \
  -u -p 14560 -s -o

保持两个终端运行，最后打开 QGC。QGC 使用 UDP 14550，jMAVSim 使用
UDP 14560，独立命令行 NSH 使用 UDP 14540，返回数据统一进入 14570。
QGC MAVLink Console 无回显时，可用终端 3 独立检查：

python3 ./PX4-Autopilot-v1.17.0-MAIN/Tools/mavlink_shell.py \
  0.0.0.0:14540

看到 NuttShell (NSH) 后说明 Shell 桥接正常。

如果 USB 设备名不同，先查看：

ls -l /dev/serial/by-id/

当前已验证的主要 SIH 参数：

SYS_AUTOSTART = 1100
SYS_HITL = 2
SIH_MASS = 0.62
SIH_IXX = 0.002016
SIH_IYY = 0.001827
SIH_IZZ = 0.00322
SIH_T_MAX = 11.3655
SIH_T_TAU = 0.02
SIH_L_ROLL = 0.175
SIH_L_PITCH = 0.131
THR_MDL_FAC = 0
L1_MOT1_SCALE = 0.8

飞控或电脑重启后，按“透明桥、jMAVSim、QGC”的顺序重新启动。


七、L1 失效飞行模式

QGC Flight Modes 中可以配置：

L1 Failure
  基于 Position；Motor 1 按参数降低输出，保持位置、高度和偏航。

L1 Altitude Failure
  基于 Altitude；Motor 1 按参数降低输出，横滚/俯仰摇杆控制倾角，
  油门控制升降，不保持水平位置，并保持偏航。

测试顺序：

1. 安全位置设置为 Position。
2. 正常解锁、起飞并稳定悬停。
3. 油门保持中位，横滚和俯仰保持中位。
4. 切入一个 L1 失效模式。
5. 确认 Motor 1 保留 L1_MOT1_SCALE 指定的输出且飞机未快速翻落。
6. 拨回 Position，确认 Motor 1 恢复100%输出。
7. 降落并锁定。

两个 L1 失效模式都禁止用于解锁，只能在正常起飞后切入。
控制器在失效模式继续保持 yaw，不应持续绕 yaw 旋转。

检查状态：

l1_adaptive_control status
listener vehicle_status 1
param show L1_MOT1_SCALE
control_allocator status

L1 Failure 的 nav_state 为 16。
L1 Altitude Failure 的 nav_state 为 7。

在 L1 Failure 模式稳定悬停后切换轨迹：

l1_adaptive_control trajectory circle
l1_adaptive_control trajectory status
l1_adaptive_control trajectory hover

第一条进入圆轨迹，第三条回到当前位置悬停。

九、main 控制参数

参数定义文件：

./Ardupoilt-to-PX4/l1_adaptive_control/l1_adaptive_control_params.c

这些数值已改为 PX4 运行时参数，不需要改控制器源码，也不需要为了调参
重新编译。控制公式、失效模式、轨迹状态机和 yaw 保持逻辑没有改变。

圆轨迹：

L1_CIR_RADIUS = 1.0       半径，m
L1_CIR_SPEED = 0.5        切向速度，m/s
L1_CIR_TRANS = 2.0        进入圆轨迹的平滑过渡时间，s

例如把半径改为 1.5 m、速度改为 0.8 m/s：

param set L1_CIR_RADIUS 1.5
param set L1_CIR_SPEED 0.8

半径和速度可在圆轨迹运行时修改；控制器会保持轨迹连续。建议先小幅增加
速度并观察位置误差，不要同时大幅修改多个参数。

起飞和手动高度：

L1_TKOFF_HGT = 1.0        自动起飞高度，m
L1_TKOFF_T = 2.0          自动起飞时间，s
L1_MAN_DZ = 0.10          高度摇杆死区
L1_MAN_VZ = 0.3           最大升降速度，m/s
L1_MAN_HMIN = 0.5         最小目标高度，m
L1_MAN_HMAX = 2.0         最大目标高度，m
L1_MAN_TOUT = 0.5         手动输入超时，s

机体参数：

L1_MASS = 0.62
L1_JXX = 0.002016
L1_JYY = 0.001827
L1_JZZ = 0.00322
L1_ARM_ROLL = 0.175
L1_ARM_PITCH = 0.131

JXX、JYY、JZZ 是三个轴的转动惯量，控制器内部自动计算其倒数。质量、
惯量和机臂必须使用实测或建模值，真机带桨前不要凭感觉修改。

几何控制器增益：

L1_KPX、L1_KPY、L1_KPZ = 14、15、15
L1_KVX、L1_KVY、L1_KVZ = 1.5、0.9、1.1
L1_KRX、L1_KRY、L1_KRZ = 0.55、0.35、0.15
L1_KOX、L1_KOY、L1_KOZ = 0.035、0.03、0.004

L1 自适应参数：

L1_ADAPT_EN = 1
L1_AS_V = -5
L1_AS_OMEGA = -10
L1_Q1_THR = 10
L1_Q1_MOM = 10
L1_Q2_MOM = 2
L1_A_THR_FRAC = 0.35
L1_A_RP_MAX = 0.35
L1_A_YAW_MAX = 0.20

电机模型和失效设置：

L1_FAIL_EN = 1
L1_MOT1_SCALE = 0.8
L1_MOT_K2 = 0.0009251
L1_MOT_K1 = 0.021145
L1_MOT_CMDMAX = 100
L1_YAW_MMAX = 1.0

L1_MOT1_SCALE 表示 Motor 1 剩余输出指令比例。真机实际推力比例受 ESC、
电机和螺旋桨曲线影响，带桨前必须标定。

查看和保存参数：

param show L1_CIR_SPEED
param show L1_MASS
param save

除圆轨迹半径和速度外，其他控制、机体和电机参数建议在锁定状态修改。
每次只改一类参数，保存修改前记录原值；如果需要恢复本版本默认值，可在
QGC 参数页对单个参数执行 Reset to Default。

修改当前参数值和固件默认值：

1. 只修改当前飞控保存的参数

例如把圆轨迹速度改为 0.8 m/s：

param set L1_CIR_SPEED 0.8
param show L1_CIR_SPEED
param save

这种方法立即修改当前飞控使用的数值，重启后仍然保留，不需要修改源码、
重新编译或刷写固件，但不会改变固件内置默认值。

2. 修改固件内置默认值

在仓库参数定义文件中修改对应的 PARAM_DEFINE_FLOAT 或
PARAM_DEFINE_INT32。例如：

PARAM_DEFINE_FLOAT(L1_CIR_SPEED, 0.5f);

改为：

PARAM_DEFINE_FLOAT(L1_CIR_SPEED, 0.8f);

不要为修改默认值而改控制器公式。修改完成后，把仓库模块同步到实际编译
使用的 PX4 源码：

cp -a ./Ardupoilt-to-PX4/l1_adaptive_control/. \
  ./PX4-Autopilot-v1.17.0-MAIN/src/modules/l1_adaptive_control/

重新编译：

make -C ./PX4-Autopilot-v1.17.0-MAIN px4_fmu-v6c_default

编译后的固件：

./PX4-Autopilot-v1.17.0-MAIN/build/px4_fmu-v6c_default/px4_fmu-v6c_default.px4

拆除全部螺旋桨、锁定飞控并关闭占用飞控 USB 的程序后刷写：

make -C ./PX4-Autopilot-v1.17.0-MAIN px4_fmu-v6c_default upload

3. 让已经保存过的参数采用新固件默认值

PX4 会保留飞控中已经保存的参数。仅刷入新固件时，旧保存值可能继续覆盖
刚修改的固件默认值。例如刷写后让圆速度采用新的默认值：

param reset L1_CIR_SPEED
param show L1_CIR_SPEED
param save

只重置需要更新的单个参数。也可以在 QGC 参数页对该参数执行
Reset to Default。不要为了一个 L1 参数执行全部参数重置，否则机型、
传感器、遥控器、飞行模式和通信设置也可能被清除。

十、真机 L1 调参流程

真机调参顺序：

基础飞行 -> 几何控制器 -> L1 自适应 -> 电机降级 -> 圆轨迹

每次只修改一个轴或一组相互对应的参数，初始修改幅度控制在 5% 到 10%。
修改控制、机体和电机参数时必须锁定飞控。首次测试必须拆桨检查电机编号、
方向和拨杆安全位置，并设置可立即切回普通 Position 的遥控器拨杆。

1. 真机固定物理参数

当前实测质量、对角惯量和有效机臂：

param set L1_MASS 1.0006
param set L1_JXX 0.00517
param set L1_JYY 0.00484
param set L1_JZZ 0.0075
param set L1_ARM_ROLL 0.12
param set L1_ARM_PITCH 0.12
param save

这些是物理测量值，不应当作稳定性调节旋钮。真机不需要修改 SIH_*。
L1_MOT_K1、L1_MOT_K2 和 L1_YAW_MMAX 只有在推力台或力矩台测量后才
能准确修改。L1_MOT_CMDMAX 保持 100。

2. 建立几何控制器基线

第一次测试关闭自适应和电机降级：

param set L1_ADAPT_EN 0
param set L1_MOT1_SCALE 1.0
param save

先在普通 Position 模式起飞并稳定悬停。普通模式不稳定时，应先检查
传感器、振动、电机方向、执行器配置和 PX4 基础控制器，不要修改 L1
增益掩盖基础问题。

普通模式稳定后切入 L1 Failure。此时只验证几何控制器。

3. 根据现象调整几何控制器

水平位置响应太慢：
对应轴 L1_KPX 或 L1_KPY 增加 5% 到 10%。

水平位置缓慢来回摆动或超调：
对应轴 L1_KVX 或 L1_KVY 增加 5% 到 10%；仍然摆动时再小幅降低
对应的 KP。

高度响应太慢：
小幅增加 L1_KPZ。

高度上下反复振荡：
增加 L1_KVZ；仍然振荡时再降低 L1_KPZ。

长期掉高但没有振荡：
先检查 L1_MASS、电池电压、电机推力曲线和输出饱和，不要先增加 KPZ。

横滚或俯仰响应太慢：
分别增加 L1_KRX 或 L1_KRY。

横滚或俯仰低频来回摆动：
分别增加 L1_KOX 或 L1_KOY；仍然摆动时再降低对应的 KR。

高频抖动、电机尖叫或发热：
降低对应轴的 KO，并检查机架振动、螺旋桨平衡和陀螺仪滤波。不要用滤波
掩盖机械振动。

yaw 缓慢漂移：
先检查电机方向、螺旋桨、Control Allocation 和偏航力矩模型，再考虑
增加 L1_KRZ。

yaw 超调或左右摆动：
增加 L1_KOZ，或者小幅降低 L1_KRZ。

切换模式瞬间翻转：
立即切回 Position。检查电机编号、旋转方向、力矩符号和分配矩阵。这不
是简单增益问题。

切换后立刻大幅掉高：
检查推力模型、质量和电机余量。输出已经饱和时，提高增益不能增加物理
推力。

4. 新质量和惯量的理论候选增益

为了大致保持旧模型的闭环动态，可在 SIH 中测试以下候选值：

L1_KPX、L1_KPY、L1_KPZ = 22.59、24.21、24.21
L1_KVX、L1_KVY、L1_KVZ = 2.42、1.45、1.78
L1_KRX、L1_KRY、L1_KRZ = 1.41、0.93、0.35
L1_KOX、L1_KOY、L1_KOZ = 0.090、0.079、0.0093

这些值是按照质量和三轴惯量比例缩放得到的候选值，不应未经 SIH 验证就
一次性写入真机。应逐轴修改并记录结果。

5. 几何控制稳定后再开启 L1 自适应

param set L1_ADAPT_EN 1
param set L1_MOT1_SCALE 1.0
param save

开启自适应后立即振荡：
降低 L1_A_RP_MAX、L1_A_THR_FRAC，或降低 L1_Q1_MOM、L1_Q1_THR。

补偿太慢且执行器输出没有饱和：
Q1_THR 或 Q1_MOM 增加约 5%。

出现高频细小抽动：
降低 Q1_THR、Q1_MOM 和相应自适应输出上限。

自适应输出长期达到上限：
先检查物理模型和执行器余量，不要继续增大上限。

yaw 在开启自适应后摆动：
先降低 L1_A_YAW_MAX。

首次真机调参不要修改 L1_AS_V、L1_AS_OMEGA 和 L1_Q2_MOM。这些参数
同时影响预测器和滤波动态，不能仅凭肉眼现象调整。

6. 最后逐步测试电机降级

L1_MOT1_SCALE 按以下顺序逐级降低：

1.00 -> 0.95 -> 0.90 -> 0.85 -> 0.80

每一级先测试悬停，不要直接进入圆轨迹。

降级后掉高且正常电机输出接近饱和：
总推力不足，应提高 L1_MOT1_SCALE。

降级后 yaw 无法保持：
提高 L1_MOT1_SCALE，并检查实际偏航力矩。

降级后缓慢位置漂移但姿态稳定：
再调整对应位置轴的 KP 和 KV。

降级后迅速翻转：
立即切回 Position。检查分配、方向和执行器余量，不要继续降低比例。

7. 保存和恢复真机调参基线

保存：

param save /fs/microsd/l1_real_baseline.params

恢复：

param load /fs/microsd/l1_real_baseline.params
param save
reboot

也可以在 QGC 参数页使用 Save to file 和 Load from file。每次试飞锁定后
结束当前日志，使不同参数试验分别保存为独立日志。

==================== 第二部分：排错与安全说明 ====================


十一、常见问题

QGC 识别不到 Joystick：

确认发射机选择 USB Joystick/HID 模式，并在 QGC 的
Vehicle Setup -> Joystick 中重新校准。

RC 摇杆正常但拨杆没有 AUX1：

确认发射机输出对应通道，并在 QGC Joystick 或 RC 通道映射中将该通道
分配给 AUX1。使用 listener manual_control_setpoint 5 或
listener input_rc 5 检查。

切换失效模式没有反应：

检查 L1 是否运行、nav_state 是否为 16 或 7，并检查
L1_MOT1_SCALE 和 control_allocator status。

jMAVSim Port busy 或 QGC MAVLink Console 没有回显：

关闭 QGC 和旧 jMAVSim，再严格按“透明桥、jMAVSim、QGC”的顺序启动。
使用 lsof /dev/ttyACM0 检查时，串口应由 mavlink_serial_udp_bridge.py

Gazebo 出现 gz_frame_id、LED 或无 GCS 警告：

SITL 传感器、EKF 和起飞功能正常时，这些通常是仿真环境提示。

切换后飞机持续旋转：

当前版本在电机降级时继续保持 yaw。持续旋转不是预期现象，应立即切回
Position 并检查电机编号、方向、输出比例和 yaw 控制输出。


十二、安全边界

- SITL 中可以使用 commander arm -f；真机禁止强制解锁。
- SITL 专用故障保护设置不得直接复制到真机。
- 真机首次验证必须拆桨，并检查电机编号、方向和拨杆安全位置。
- 真机飞行前需要重新确认质量、惯量、机臂、电机和螺旋桨参数。
